¿Cómo generar la Contraseña?

1 Ingresa a tu panel de WordPress (/wp-admin).
2 En el menú lateral ve a Usuarios → Tu perfil (o Perfil).
3 Baja hasta la sección Contraseñas de aplicación.
4 Escribe un nombre (ej: Rebooy Panel) y presiona Añadir nueva contraseña.
5 Copia la clave de 16 letras generada y pégala arriba.
Seguro: Las contraseñas de aplicación no revelan tu contraseña maestra de WordPress y pueden revocarse en cualquier momento con un clic.

Requisitos de WordPress

  • WordPress versión 5.6 o superior (incluye Application Passwords de forma nativa).
  • La REST API debe estar habilitada (ruta predeterminada /wp-json/wp/v2/ activa).
  • El usuario debe contar con rol Editor o Administrador para poder crear entradas.
